How is this free?

This prototype runs entirely in your browser and saves data on your device. It uses a lightweight story engine—not a paid cloud AI model—so it has no API bill. Replies are structured and contextual, but won't be as open-ended as a full language model.

Memory controls

Memories are automatically noted after key events and can also be added manually. Clearing site data in your browser may erase them. Export a backup if you want to keep them.

Prototype limitations

No remote AI is called. This keeps running costs at $0, but responses come from local story templates and context rules rather than a large generative model. A truly open-ended LLM with no API fees would require running a model locally on compatible hardware; iPhone browser support varies and can be resource-intensive.
